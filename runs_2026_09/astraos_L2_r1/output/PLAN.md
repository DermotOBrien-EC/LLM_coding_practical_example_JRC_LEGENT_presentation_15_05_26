# German hourly load forecast plan

1. Read `opsd_de_load.csv` with pandas and validate timestamps, units, duplicates, non-finite or non-positive loads, and hourly continuity. Preserve the UTC timestamp convention of the source. Hold out exactly 2020-01-01 00:00 UTC through 2020-01-07 23:00 UTC. Ignore all later observations.
2. Write `test_forecast_load.py` before `forecast_load.py`. Exercise the consumer-facing forecasting function, the exact holdout boundary, historical-only feature construction, rejection of contaminated training data, missing data handling, and independently calculated error metrics.
3. Implement a fixed-origin, 168-hour forecast in `forecast_load.py`. Use calendar features in Europe/Berlin time (hour, weekday, annual cycle, German holidays and the year-end holiday period) and historical load lags of at least 168 hours. No observed target-week loads, weather observations, backward filling, centered rolling windows, or random train/test split may enter predictions. Fit histogram gradient boosting models with fixed seeds and no automatic early-stopping split.
4. Select between two small predeclared model configurations, with 15 or 31 leaves and otherwise identical settings, using mean absolute error on five historical 168-hour holdouts starting 2018-01-01, 2019-01-01, 2019-11-25, 2019-12-09, and 2019-12-23. Each fold uses only data before its own origin. Compare a repeat-last-week baseline on those same folds. Freeze the chosen configuration before examining target-week accuracy, then refit on all eligible pre-2020 observations.
5. Save `outputs/forecast.csv`, `outputs/metrics.json`, `outputs/validation.csv`, `outputs/forecast_vs_actual.png`, and a concise report. Plot two clearly distinguished actual/forecast lines on one load axis, with an aligned error panel, a legend, UTC labels, and a CSV table equivalent. Report MAE, RMSE, MAPE, mean signed error, and improvement against the seasonal baseline.
6. Run pytest, Ruff and strict mypy, execute the script end to end, recompute headline metrics directly from the saved CSV, inspect the rendered plot, and obtain a non-author peer review. Add `requirements.txt` and `README.md` with exact reproduction commands, data provenance, assumptions, results, and limitations. Do not commit or publish anything.

The operator authorized end-to-end unattended completion, so this plan proceeds without an interactive approval gate.

## Independent plan challenge

The non-author peer approved the plan with caveats. Accepted changes: add a 52-week (8,736-hour) baseline because the previous-week baseline copies Christmas; include a trailing seven-day mean shifted by 168 hours; represent Epiphany and Christmas/New Year's Eve separately from national holidays; include previous-day and two-days-prior national holiday flags so bridge-day effects can be learned. Pin early_stopping=False and test the fitted iteration count. Define signed error as forecast minus actual. Exact bridge-day effects and regional holiday load weights remain approximate without regional data. The reviewer inspected the CSV independently and found it complete; historical data quality and coverage were also checked locally.
